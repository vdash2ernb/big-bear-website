# Copper-and-steel identity

The user supplied `6543b3da-7581-457d-94cd-90472422a446.png` as the replacement identity. The original board is preserved in `source-assets/brand-identity-copper.png`.

The header and footer use the BB/bear emblem with a horizontal HTML wordmark and the supplied tagline: **SMART ACCESS. BUILT TO LAST.** The browser icon uses the emblem. The site's palette now follows charcoal #2b2b2b, copper #b87333, warm white #f7f5ef, and steel-gray details. Button text uses #111 for readable contrast on copper.

The built-in image-generation tool prepared the emblem from the supplied board. Prompt: isolate the large upper-left symmetric BB/bear gate emblem, preserving brushed steel outer B shapes, paired copper vertical bars, bear eyes/nose, proportions, and design; omit text and other board elements. The first requested transparent version contained a baked checkerboard and was rejected. A targeted repair replaced that checkerboard with a plain #2b2b2b charcoal background while preserving the emblem. The accepted version is opaque, not a transparent or vector master. Browser sizes are resized copies without further creative changes.

The board's sign, truck, and clothing mockups are branding references, not evidence of real completed projects; they have not been added to the project gallery. The existing real gate photographs remain in use.

Earlier blue-logo assets remain archived locally but are not referenced by the pages. For future production print work or exact vector geometry, obtain a vector master from the brand designer.
